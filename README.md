# AFF定例資料作成ツール

## 概要
デイリーレポート・コストレポート・AF実績データをもとに、
定例会資料用の画像を自動生成するツールです。
生成した画像は個別PNG保存およびZIP一括ダウンロードが可能です。

## 入力ファイル
① デイリーレポート
 対象シートのみを残したExcelファイルをアップロードしてください。
【前提】
- 数式解除済み
- パスワード解除済み

② コストレポート
 対象シートのみを残したExcelファイルをアップロードしてください。
【前提】
- 数式解除済み
- パスワード解除済み
利用項目
列| 内容
A列| 日付
C列| 申込 Forecast
D列| 申込 実績
K列| 発行 Forecast
L列| 発行 実績
Q列| 目標承認率
R列| 承認率
T列| Forecastコスト
U列| 発行コスト
Y列| 目標CPA
Z列| 発行CPA

③ AFコードマスタ
 GitHub上の AFF_AFコード.xlsx を参照。
【構成】
列| 内容
A列| AFコード
- 1行目：ヘッダー
- 2行目以降：AFコード
AFコード追加時はGitHub上のExcelを更新すること。

④ AF申込実績データ
 AFコード別申込実績をアップロード。
【構成】
位置| 内容
A列| 日付(YYYYMMDD)
1行目| AFコード
B2以降| 申込件数

⑤ AF発行実績データ
 AFコード別発行実績をアップロード。
【構成】
位置| 内容
A列| 日付(YYYYMMDD)
1行目| AFコード
B2以降| 発行件数

## 出力
① 全体実績
 出力内容
- 全体CV
- COST
- 承認率
- 申込CPA
- 発行CPA
- 日別推移グラフ

② 還元サイト実績
 出力内容
- CV進捗ゲージ
- Target
- Actual
- 日別推移

③ 非還元サイト実績
 出力内容
- CV進捗ゲージ
- Target
- Actual
- 日別推移

④ AF実績
 出力内容
- AFCV進捗
- AF承認進捗
- AF発生件数
- AF承認件数
- AF発生CPA
- AF承認CPA
- 日別推移グラフ

## AF発生集計ロジック
AFコードマスタに存在するAFコードのみ集計対象。
AF発生件数 = AFコードマスタ × AF申込実績データ
集計期間内合計

## AF承認集計ロジック
AFコードマスタに存在するAFコードのみ集計対象。
AF承認件数 = AFコードマスタ × AF発行実績データ
集計期間内合計

AF目標
全体実績のCV目標を使用。
ポイントサイト目標 ＋ 比較サイト目標

AF発生CPA
実績CPA = 発行コスト ÷ AF発生件数

想定CPA = Forecastコスト ÷ AF目標

想定比 = 想定CPA ÷ 実績CPA

AF承認CPA
実績CPA = 発行コスト ÷ AF承認件数

想定CPA = Forecastコスト ÷ 発行Forecast

想定比 = 想定CPA ÷ 実績CPA

⑤ 媒体別分析
 出力内容
- CV進捗ゲージ
- Target
- Actual
- CT推移
- 日別グラフ
サイト単位で切替表示。

出力形式
・PNG
各画像を個別保存可能。

・ZIP
生成画像をZIP形式で一括ダウンロード可能。

## メンテナンス
AFコード追加
GitHub上の AFF_AFコード.xlsx を更新。
アプリ側の修正は不要。

## 集計期間
サイドバーの「集計期間」で指定。全画像共通で適用。
